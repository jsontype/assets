HTML Structure

The template includes 9 html files. This template is a flexible layout with max 3 column. All of the information within the main content area is nested within a div with a class of "page". You have to open index page in order to change it.

CSS Files and Structures

I'm using 7 CSS files in this template. If you would like to edit a specific section of the site, simply find the appropriate label in the CSS file, and then scroll down until you find the appropriate style that needs to be edited.
