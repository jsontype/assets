01Installation

Follow the steps below to setup your site template:

  1. Download and Extract the Zip File : Download the zip file containing all files integrated with Medizen. Extract the contents of the zip file to your desired location.
  2. Install PHP : If you're using XAMPP, WAMP, or MAMP, PHP should already be included. Make sure your server environment (Apache, Nginx, etc.) is configured to work with PHP. If PHP is not installed, you can download it from the official PHP website: PHP Downloads.

02PHP Structure

We are used Bootstrap Latest Version v5.0.0 framework in this template.
The general template structure is the same throughout the template. Here is the general structure.

    
        

        <?php $head_title="Home || Medizen || Medizen PHP Template"?>
        <?php $body_class="body-bg"?>
        <?php require_once('parts/layout/top-layout.php'); ?>
        <?php require_once('parts/header/header.php'); ?>

        <?php require_once('parts/home/banner.php'); ?>
        <?php require_once('parts/home/category.php'); ?>
        <?php require_once('parts/home/about.php'); ?>
        <?php require_once('parts/home/appoentment.php'); ?>
        <?php require_once('parts/home/feature.php'); ?>
        <?php require_once('parts/home/sponsor.php'); ?>
        <?php require_once('parts/home/choose.php'); ?>

03Favicon Settings

Favicon Will be found in <head> section.

    
    <link rel="shortcut icon" type="image/x-icon" href="assets/img/favicon.png">

04Logo Settings

The Logo will be found in the <nav class="navbar"> tag.


        <div class="logo"><a href="index.php"><img src="img/logo/logo.png" alt="logo"></a></div>

You can replace any .jpg .png .svg logo. And set the width according to your logo size.

05Fonts Settings

In Medizen we use Outfit and Syne font.
You can change font form css/main.css: 

                
                    @import url("https://fonts.googleapis.com/css2?family=Outfit:wght@100..900&amp;family=Syne:wght@400..800&amp;display=swap");

07CSS Structure

The style.css file contains all of the specific stylings for the page. The file is separated into sections using:

  • font-awesome.css
