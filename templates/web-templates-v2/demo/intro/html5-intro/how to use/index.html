D) New Version – Real Estate Intro (v4) - top

This version introduces a new Real Estate intro concept with improved sound handling, dynamic frame detection, and a new premium text animation effect.

1. User Trigger Autoplay Sound (Browser Safe)

Due to modern browser policies, audio playback now starts only after user interaction.

Features:

  • Sound starts after clicking the Play Intro button
  • No autoplay blocking on Chrome, Firefox, Safari, Edge
  • Smooth fade-in when sound starts
  • Smooth fade-out when intro ends or redirects

Important: Do not remove the Play Overlay button. Audio playback requires user interaction.

  <button id="btnPlay">Play Intro</button>
</div>

2. Dynamic Frame System (Auto Detect Frames)

You no longer need to manually change the total frame number.

The system now automatically detects all frames using the frame ID format:

<section id="frame1" class="frame">...</section>
<section id="frame2" class="frame">...</section>
<section id="frame3" class="frame">...</section>

JavaScript (intro.js):

var frames = $('[id^="frame"]');
var pagenum = frames.length;

Benefits:

  • No manual update needed when adding or removing frames
  • More flexible intro system
  • Perfect for creating multiple intro variations
3. New Fall Text Letter Animation Effect

A new premium animation effect has been added: letter-by-letter falling text animation.

Usage:

<h1 class="fall-text intro" data-time="600">Discover Your Dream Home</h1>

Features:

  • Each character animates individually
  • Smooth cubic-bezier easing
  • Real spaces preserved (no broken spacing)
  • Text stays visible after animation (no fade-out)

JavaScript:

$('.fall-text').each(function () {
  var text = $(this).text();
  var html = '';
  var delay = 0;

  for (var i = 0; i < text.length; i++) {
    var char = text[i];

    if (char === ' ') {
      html += ' ';
    } else {
      html += '<span style="animation-delay:' + (delay * 0.08) + 's">' + char + '</span>';
      delay++;
    }
  }

  $(this).html(html);
});

CSS:

.fall-text span {
  display: inline-block;
  opacity: 0;
  transform: translateY(-40px);
}

.fall-text.intro span {
  animation: fallIn 0.8s cubic-bezier(.19,1,.22,1) forwards;
}

@keyframes fallIn {
  0% {
    opacity: 0;
    transform: translateY(-40px);
  }
  100% {
    opacity: 1;
    transform: translateY(0);
  }
}
